# QQ 图片、表情与文件素材

[返回首页](../README.md) · [MCP 工具](MCP.md) · [自由群聊](SOCIAL_CHAT.md)

本文描述开发分支，已发布的 v0.8.0 EXE 尚不包含此功能。素材库保存用户明确批准给某个账号和群的字节，AI通过不透明编号挑选，不获得任意磁盘或下载权限。

## 导入并补充描述

1. 先在账号中配置群的读取范围并应用。素材页只显示当前账号**已经应用且允许读取**的群，草稿中新增的群暂不能使用。
2. 打开「模块 → QQ 图片、表情与文件素材」，选择“导入图片、表情包或文档”，选择文件及用途：表情包、图片或文件。
3. 勾选允许使用此素材的群，填写名称、标签和描述后导入。导入是本地资料操作，不会自动发送，不表示QQ已经登录，也不会释放账号权限。
4. 在素材卡中编辑描述／标签，或按需执行下文的显式视觉识别。群友聊天时只会得到该账号、该群已批准素材的编号与缓存资料。

描述应写清画面含义及合适的语境，例如“点头赞同，适合轻松讨论；不用于严肃通知”。表情并非每次都要发；AI应结合上下文、情绪、适用和避免场景，不合适或拿不准时回复文字或保持沉默。图片、图片里的文字和识别结果都属于不可信资料，不能修改权限或冒充群友的新要求。

表情发送使用固定的自定义图片子类型 `sub_type:1`，普通图片保持默认类型；字段依据 [NapCat接口及映射](https://github.com/NapNeko/NapCatQQ/blob/13a8a2b8dd962fa63b3bc99a2d29eac0bf78e8ec/packages/napcat-onebot/api/file.ts#L62)。它不等于商城表情、超级表情或自动收藏，实际显示仍需按QQ客户端验证。

## 可选：让视觉模型识别表情

**DeepSeek内置文字通道不能识图。** 当前界面保持每账号单选主LLM，素材识别只使用本账号当前已启用且支持图片输入的兼容API；仅使用DeepSeek时先填写手工描述和标签。模型名称出现在列表中不等于已验证具备视觉能力，需按实际服务确认。

素材页不会额外启用第二条模型通道。独立专用视觉通道属于 [后续建议](TOOL_ROADMAP.md)，本轮尚未实现；DeepSeek仍可根据手工描述和标签选择素材。

当前账号启用支持图片的兼容API后，在素材页选择它，点击某张图片的“AI 识别标签”才会提交这张已批准素材并产生该API的费用。保存结果包含描述、标签、情绪、适用和避免场景，并标明识别来源；以后聊天读取这些缓存文字，无需再次识图。不会因为群友发图、调用 `describe_asset` 或同步收藏表情就自动调用视觉API，也不会在失败后换另一服务计费。

单次分析最多4 MiB图片、45秒及768输出token。GIF等动图按静态输入范围处理，不能声称看懂了完整动画。分析期间删除／编辑素材、切换模型或Key、改变账号范围、取消或退出，旧结果不会覆盖新资料。失败时可继续手动编辑标签。

## 从 NapCat 同步本人的 QQ 收藏表情

先在NapCat实际登录并连接当前QQ，在素材页勾选目标群，再点击同步收藏表情。后台通过当前已验证连接的 `fetch_custom_face` 读取本人收藏表情，**它与QQ内置“我的收藏”通知／文件整理是两项功能**，也不是导入NapCat插件。

每次最多10项、累计下载40 MiB、总时限120秒；重复图片也占下载预算。只从精确的 `p.qpic.cn`、`gchat.qpic.cn`、`multimedia.nt.qq.com.cn` 的公开HTTPS地址读取，不带Cookie，不接受群友给的下载URL，重定向、DNS与实际连接IP都要通过核对。签名地址不写入素材清单或回执。

相同内容按SHA在整个本账号素材库查重；只有已有素材已经覆盖本次全部目标群时才复用，不会因此自动扩大旧素材的群范围。同步只导入字节，默认注明“尚未进行图像识别”；不会自动分析或产生视觉API费用。之后由本人选择素材、编辑标签或单独点击识别。取消、身份变化或未知结果会停止后续处理，已完成的素材保留，不自动重试。

该功能以NapCat历史公开提交的接口事实实现，实际可用性取决于所用连接端；没有完成真实QQ在线验收。收藏可访问不代表获得图片的再分发许可，本应用不附带这些图片。接口来源与许可见 [MCP参考说明](MCP.md#参考方式)。

## 允许 AI 自然使用

在「场景与权限 → 选定群与消息权限」展开目标群的“自由聊天与主动话题”，进入“活动时段、调用预算与素材工具”，按需勾选“允许 AI 按语境使用的 QQ 回复动作”。可选表情包、图片、文字／真实@／引用、消息回应和戳一戳，默认全关。

同时启用自由聊天、工具总开关和内置QQ MCP，允许本群读取与发送，保存、应用并启动账号。默认自然互动冷却30秒、每群每小时6次，和主动模型预算分别限制。AI可以只发表情后安静，不强行附一段文字；成功互动仍可接住后续提问。

这份预授权不包含文件、合并转发、撤回或其他应用写入。普通文件请求仍需明确调用人和对应写工具许可。群友说“发一下那份文件”时，AI只能从批准给本群的文件中选择，不能根据路径或网址访问电脑。

## 格式、回执和备份

| 项目 | 范围 |
| --- | --- |
| 图片／表情 | PNG、JPEG、GIF、WebP，最多8 MiB；校验图像头、尺寸及动画预算，不接收SVG或任意URL |
| 文件 | txt、md、csv、json、pdf、docx、xlsx、pptx，最多20 MiB |
| Office | 仅做受限ZIP目录校验并传输，不解压、不执行，不代表已读取正文；拒绝宏、路径重定义、嵌入对象和夸张压缩比 |
| 每账号素材库 | 最多1000项、合计200 MiB |
| 模型接触内容 | 有界元数据和 `assetId`；二进制仅交给宿主发送／本人显式视觉分析 |

QQ消息、图片和文件发送必须取得连接端的实际回执才记为确认成功。文件较大时先分块传入NapCat，再发布到原群，Windows原生与Docker不依赖共享本机目录。连接端不支持或投递未知时停止，不自动换路径重发。

素材页的“最近 QQ 动作回执”区分核对中、已提交、确认成功、未执行、已取消和结果未知，记录必要目标及素材编号，不保存图片字节、密钥或模型提示。结果未知时先到QQ核对实际情况。

素材及描述保存在各账号原资料目录的 `qq-assets/`，动作记录为 `qq-actions.json`；选择自定义记忆目录不会搬走它们。完整备份需在退出应用后同时保留主资料目录及自定义记忆目录，见 [备份指南](USAGE.md#7-数据升级与备份)。
