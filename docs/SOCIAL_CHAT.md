# 自由群聊、主动分享与群友记忆

[返回首页](../README.md) · [使用指南](USAGE.md) · [插件开发指南](PLUGIN_DEVELOPMENT.md)

v0.6.0 可以把选定群里的助手配置成持续参与对话的群友：接住连续追问、判断何时接话，也能发现有趣的视频链接后主动开启话题。新能力默认关闭，升级后保留原来的触发方式和权限。

## 先让它正常回答

1. 在「账号控制」完成实际 QQ 登录，选择并测试一个 API 模型，开启「聊天与回复」。ChatGPT／Codex 个人订阅仍只供本人任务，不参加自动群聊。
2. 在聊天参数中填写 AI 的名字、别名、人设和兴趣。
3. 进入「场景与权限 → 选定群与消息权限」，选中目标群并允许读取与发送，在该群的详细设置中开启「自由聊天」。按需选择 @、叫名字、引用回复、戳一戳等触发条件。
4. 保存、应用参数，再显式启动账号／确认授权范围。普通应用参数仍会恢复只读，不能省略最后的授权。
5. 在测试群 @ 实际登录的 QQ 提问，再发一条相关追问。查看日志确认模型和发送结果。

自由聊天会保存群友输入和实际送达的 AI 回复，约 1.5 秒内的连续短消息会合并处理，最长等待 3 秒。相关追问在默认 120 秒的会话窗口内可以继续，不必每句重新 @。名字与别名用于识别称呼，不把名字出现的任意子串都视为呼叫。

AI 可以选择沉默。没有明确找它时，是否参与取决于当前话题、兴趣、近期发言和预算；明确提问优先于主动闲聊。没有授权工具的普通问题仍可正常回答。

## 让 AI 自己找话题

在目标群的详细设置中开启「主动话题」，填写这个群的兴趣或补充说话风格，再选择允许它使用的**背景只读工具**。例如导入并启用 [Bilibili 示例插件](../examples/plugins/bilibili-assistant)，允许热门、搜索或视频详情工具，AI 就能寻找候选视频并通过 QQ 分享链接。

后台按检查间隔提供机会，AI 结合当前群语境、已确认的记忆和素材判断是否值得说，可以分享、继续原话题或保持沉默。**没有“安静满 60 分钟”或“每天必须／最多开两次话题”的固定规则。** 默认检查间隔为 10 分钟，不代表每 10 分钟发一条消息；重复、过时或不相关的素材应跳过。

| 设置 | 默认值与含义 |
| --- | --- |
| 主动活动时段 | 运行电脑本地时间 10:00–22:00，可按群修改 |
| 主动检查间隔 | 至少间隔 10 分钟考虑一次机会，可调整 |
| 自主模型调用预算 | 每群每小时 12 次、每账号每小时 30 次；工具链后续模型请求也计入 |
| 非直接互动的发言上限 | 每群每小时 6 次，用于防止频繁插话 |

直接提问和相关追问不占自主发言预算，仍受正常队列和防刷保护。判断沉默也可能消耗一次模型请求；预算是限制机会，不是要求把次数用完。应用须保持运行，退出、休眠或断线期间不运行，也不在恢复后补发错过的话题。

背景只读授权与群友手动请求的工具授权分开。已允许某位群友调用工具，不代表 AI 可以在后台借用该成员身份。后台主动分享不自动发表评论、@ Bilibili 用户或执行其他外部写入；这些仍需要人的明确任务和既有写权限。群消息、工具结果和 Skill 也不能替代后台权限检查。

Bilibili 示例目前根据标题、简介、UP 主等元数据筛选，分享的是链接与基于可获取资料的推荐理由；没有播放视频、解析音频或完整视频理解。插件功能调用不是标准 MCP stdio／HTTP 接入。

## 开启和审核群友记忆

打开「设置 → 群友记忆 → 查看记忆」，在目录中找到账号、实际登录 QQ、群和成员。进入群后开启记忆；暂停会停止该群的记忆使用和新候选整理，保留已有记录。

记忆也可单独开启：不启用自由聊天时，原来已授权的 @ 等触发仍可使用记忆并提出候选，保持原触发条件和冷却，不会因此自动开启插话或后台话题。关闭短期上下文条数不会关闭当前提问者的已确认长期记忆。

- AI 只提出群友明确说过的事实、兴趣和偏好，不推断性格或关系。
- 候选随正常聊天回复的模型调用产生，不另外安排付费记忆抽取任务。
- 选择候选可以查看原文摘录、来源消息和时间。**确认后才用于后续聊天**；也可以修改、拒绝、删除或手动新增。
- 原有确认内容不会被新候选自动覆盖。昵称只用于显示，同名群友仍按成员 QQ 区分。

记忆隔离范围为「账号配置＋实际登录 QQ＋群号＋成员 QQ」。同一成员在其他群里的记忆不会自动带入；同一配置改为登录另一个 QQ，也不会继续沿用旧身份记忆。

双向聊天上下文默认保留 30 天，与通知消息的保留天数分开。已确认记忆及必要证据摘录独立保存，应用重启、通知清理、暂停记忆或功能参数还原默认不会删除它们；需要移除时在记忆窗口删除。完整备份仍应在退出应用后复制整个资料目录，见 [数据与备份](USAGE.md#7-数据升级与备份)。

## 不说话时检查什么

| 现象 | 检查方式 |
| --- | --- |
| @ 也没回应 | 确认实际 QQ、API 连接、聊天开关、群读取与发送、已保存参数和最后的账号授权 |
| 正常回答，但不主动聊天 | 确认该群开启自由聊天／主动话题；检查活动时段、调用预算及日志中的沉默原因 |
| 想分享视频但没有素材 | 安装并启用插件，检查该群独立的背景只读工具白名单；手动请求授权不会自动复制到这里 |
| 偶尔选择沉默 | 这是合法决策，表示当前内容不适合参与，或时段、预算、重复内容等条件未满足 |
| 记忆没有出现 | 先开启该群记忆；候选仅随正常回复产生，不保证每次聊天都有候选 |
| 记忆存在却没用上 | 检查实际 QQ／群／成员是否一致、状态是否已确认，以及该群是否暂停记忆 |
| 改完参数突然不回复 | 应用参数会恢复只读，确认范围后重新释放权限 |

自动测试使用模拟 OneBot、模型与工具返回，不代表真实 QQ、视频推荐质量或 Bilibili 评论已通过在线验收。当前实测范围见 [验证记录](VALIDATION.md)。
