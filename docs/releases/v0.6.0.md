# QQ_Service v0.6.0

本版加入自由群聊、内容驱动的主动分享和真正接入后台的群友记忆管理。

- **自然聊天**：保存双向对话、合并连续短消息并接住相关追问；统一普通聊天和工具入口，没有授权工具时仍能回答普通问题。
- **自主参与**：逐群开启自由聊天和主动话题，由 AI 判断接话、分享或沉默。支持独立授权的背景只读工具，例如寻找 Bilibili 视频并分享链接；频率受活动时段、调用预算和防刷保护约束，没有固定每日开话题次数。
- **群友记忆**：在设置中按账号、实际 QQ、群和成员查看候选及证据，确认后才用于聊天；支持编辑、拒绝、删除、手动新增和逐群暂停。已确认记忆独立保存。
- **插件与工具**：正式交付自定义插件、模型工具调用、独立加密插件凭据与 Skill 配置；外部写入仍需要明确的人为请求和额外授权。
- **权限与升级**：旧群保留原行为，新能力默认关闭；应用参数后仍需重新确认授权范围。个人 ChatGPT／Codex 订阅不用于自动群聊。

使用步骤见 [自由群聊与记忆指南](https://github.com/klwb360/QQ_Service/blob/main/docs/SOCIAL_CHAT.md)。升级前完全退出旧应用并备份资料目录，再运行新版 EXE。

Bilibili 推荐依据当前可获取的视频元数据，不包含完整视频观看。自动验证不替代真实 QQ、模型服务和 Bilibili 在线联调；具体结果见仓库验证记录。EXE 当前未签名，下载后可使用配套 SHA256 文件核对。
