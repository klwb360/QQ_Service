# QQ_Service v0.7.0

本版将模型接入统一为 API，移除 ChatGPT 订阅／Codex 的安装、登录和推理流程，让账号配置更直接。

- **仅通过 API 接入模型**：保留 DeepSeek、OpenAI、百炼、智谱、Kimi、硅基流动及自定义兼容 API。账号下拉栏、模块页和后台不再提供订阅登录或 Codex CLI 执行入口。
- **旧订阅配置迁移**：首次迁移前将原配置备份为 `config.pre-api-only.backup.json`；停用原订阅场景、清空对应模型选择，并让相关账号恢复只读。需主动选择 API、填写 Key、测试和重新授权，不会自动切到 DeepSeek 或其他计费通道。
- **保留现有资料**：已有 API 配置和权限保持；旧订阅安装、认证和工作目录不自动删除，也不再读取认证或运行 CLI。QQ 连接、群友记忆、插件及历史任务继续保留。
- **机器人专用 API 指南**：新增 [配置步骤](https://github.com/klwb360/QQ_Service/blob/main/docs/OPENAI_API_SETUP.md)，说明如何激活符合条件的 Pro／Business API 额度、在正确组织中创建专用项目和 Key、限制权限及填写应用参数。额度需实际领取；有效期、模型权限和用量限制以官方控制台为准。

自由群聊、内容驱动的主动分享、群友记忆审核、通知汇总和收藏列表整理继续使用所选 API；QQ 读取、发送与显式账号授权规则不变。

验证结果见 [验证记录](https://github.com/klwb360/QQ_Service/blob/main/docs/VALIDATION.md)。Windows 发布流程执行语法检查、自动测试、便携 EXE 构建、包内资源校验和 SHA256 生成。模拟 OneBot／模型测试不替代真实 QQ、模型 API 和 Windows 桌面实机验证。

升级前完全退出旧应用并备份现有资料目录，再运行新版。EXE 当前未签名；下载后请用配套 SHA256 文件核对。
