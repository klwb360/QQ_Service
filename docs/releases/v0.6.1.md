# QQ_Service v0.6.1

本版修复 v0.6.0 群消息处理与群友记忆的三项回归。

- **超长群消息**：会话入库文本限制为 12000 字符，避免存储校验异常中断普通聊天、工具或插件处理；各模块原有输入限制继续生效。
- **引用回复**：回复 ID 同时支持 OneBot 消息段数组与 CQ 字符串，兼容负数 ID、参数顺序与一次实体解码；仍仅识别当前实际 QQ、当前群中机器人的已送达消息。
- **群友记忆**：查询优先保留本轮参与者，再按最近历史补齐，最多 20 人，避免当前请求者的已确认记忆被较早历史排序排除。
- **版本显示**：统一包版本、界面标识、下载地址和当前开发文档为 v0.6.1。

保留多账号隔离、默认只读、显式释放权限、群读取与发送检查、工具写入授权及旧版配置兼容；升级不会自动扩大权限。

修复提交已通过 Linux 自动测试和 Windows CI 的语法检查、自动测试、便携 EXE 构建及包内资源校验。模拟 OneBot／模型与自动化测试不替代真实 QQ 登录、付费模型、Windows 原生扫码和多账号桌面实机验证。

升级前完全退出旧应用，并备份现有资料目录。新版沿用原有资料路径；下载 EXE 后请用配套 SHA256 文件核对。EXE 当前未签名。
