# QQ_Service v0.8.0

本版完善人格与记忆连续性，并增加 Docker 网页部署。

- 人格：统一普通、自由聊天和工具助手设定，支持 Markdown 导入导出、草稿预览及已应用版本回退。
- 记忆：改善中文相关性检索，保留确认式成员事实；新增有真实互动来源、可暂停和回退的自动经历札记。
- 会话：独立保存两小时有效的话题、近期参与者和待续事项，可清空短上下文而保留长期记忆。
- 连接：增加 NapCat / SnowLuma 适配层、独立凭据与能力声明，以及切换去重。SnowLuma 未完成 Windows 隔离检查，入口仍禁用。
- Docker：服务端与网页仪表盘支持 Compose，默认 `127.0.0.1:8787`、非 root、只读根目录和持久数据卷；QQ 连接端外部运行。
- 升级：schema 1/2 自动迁移至3，保留稳定账号 ID、原人设、密钥及历史，不新增发送权限。

Windows EXE 仍未签名。Docker 不包含 Electron 窗口或托盘，也不会启动宿主机 NapCat。
