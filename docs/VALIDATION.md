- Linux `npm test`：93 项中 91 项通过，0 项失败，2 项可选 GUI 检查在普通发现中跳过，另行执行。`npm run check` 通过，涵盖新增配置、引导与桌面文件。
- 多组兼容 API 的配置、稳定 provider ID、独立密钥、文字接口请求、错误解释、重定向拒绝、导出脱敏与模型选择有自动覆盖；模型失败不切换其他计费通道。服务商预设不代表该服务全部模型已实测。
- 结构化字段校验覆盖可选私聊接收对象：纯群/本地用途可使用同号配置；启用私聊回复或私聊汇总时才要求另一个接收 QQ，并提供关闭私聊的修正路径。
- 引导按真实配置、OneBot 连接身份、模型测试和授权分别显示。测试指纹随模型/Key 改变失效；拒绝连接、端点错误、鉴权、QQ 未登录和身份不一致分别提供处理动作。连接与群列表发现保持只读。
- 群触发支持 12 种条件组合、默认 @、旧单值兼容与显式空数组。模拟真实通知形态检查群名变化等事件；群发送仍核对账号、读取/发送范围、API 聊天和冷却，不授予群管理操作。

- 9 项实际 Electron 账号与后台流程检查通过，覆盖配置、独立账号导出、单实例、托盘、完全退出和重启保留资料。
- 8 项实际 Electron 窗口检查通过：自绘标题栏、真实最小化/最大化/还原状态、关闭偏好持久化、托盘与退出、无托盘回退，以及来自非受信窗口的特权 IPC 拒绝。图形环境使用 Linux Xorg/xfwm4，不代替 Windows 桌面实机操作。
