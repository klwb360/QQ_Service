# 前端编辑进阶预览版

此预览版以用户导出的 `QQ_Service-ui-design.json`（18 处修改）作为新界面起点，只调整前端展示与编辑体验。QQ 接入、模型调用、账号数据和权限处理沿用上一版。

## 已落实的界面修改

- 左侧导航显示为「仪表盘、账号、权限、模块、日志、设置」。
- 仪表盘标题显示为「仪表盘」。
- 移除连接区域已隐藏的安装路线按钮和说明，以及被清空的连接标题、描述。
- 连接参数区标题显示为「NapCat 的连接信息」。
- 日志页不再显示原有标题和描述。

这些修改成为程序默认界面。编辑器的「全部恢复」回到这一版的起点，已从源码移除的内容不会再次出现。旧版导出的这份配置可继续载入，已有相同修改会合并处理。

## 继续编辑与交接

1. 打开右上角「编辑界面」，选择页面中的文字、按钮、下拉栏或容器。
2. 需要调整整块内容时，使用父级选择功能。修改文字、样式或显隐后，可通过预览检查布局。
3. 完成后点击「导出 JSON」，把导出的文件发回来，作为下一轮前端修改及后端功能实现的依据。

编辑结果保存在本机用户资料目录中的 `ui-design.json`，不会写回 EXE。导出文件只包含手动编辑的展示属性；账号配置、密钥和消息不属于界面设计文件。

删除展示内容与停止相应功能分别处理。后续若需要改变按钮动作、配置含义、权限或模型行为，将依据最终确认的界面另行实现。

此版本仅用于本地预览，不创建 GitHub Release。
