# 界面搭建预览版

此版本提供本地可视化搭建能力。QQ 接入、模型调用和账号权限继续使用现有业务逻辑；新组件的后端功能可以在最终界面确认后接入。

## 开始搭建

1. 打开右上角「编辑界面」，进入「搭建菜单与组件」。
2. 在「菜单与页面」填写名称并创建，左侧立即出现新菜单。
3. 在组件库点击标题、文本、按钮、下拉栏、输入框、多行输入、开关、卡片容器或分隔线，将其添加到选定页面。
4. 点击自建组件，在面板内修改文字、样式、说明、选项和所在页面；卡片可设置一到三栏。
5. 使用拖动或上下移动按钮排列组件；通过目标页面和父容器设置移动组件及其子项。也可以把组件直接拖入卡片。
6. 切换到「预览并操作」，检查跳转、输入框、下拉栏和开关的展示效果。

自建页面可以改名、修改标题和说明、排序或删除。原有菜单也可以排序。自建组件支持复制、删除、嵌套和跨页面移动；原有业务元素可在「编辑已有元素」中修改展示。

## 按钮动作

- 无动作：只展示按钮。
- 页面跳转：打开应用中已有或自建的页面，预览及正常模式均可使用。
- 待接入功能：填写希望后续实现的行为说明。预览点击时显示这段说明，说明会随界面设计一起导出。

编辑模式下点击组件只会选中它。新增控件不读取账号数据，也不触发 QQ 操作或模型调用。

## 保存与交接

设计会自动保存到本机资料目录中的 `ui-design.json`。菜单、页面、组件和样式重启后仍可恢复；输入框的临时内容、下拉栏的预览选择和开关的预览状态不作为设计保存。

编辑结束后点击「导出 JSON」，把导出的文件发回，作为下一轮界面修改和后端功能实现的依据。文件包含展示修改及声明式布局，不包含账号配置、模型密钥或消息。

旧版 version 1 界面文件仍可导入。首次创建或调整布局后保存为 version 2。「撤销」「重做」覆盖菜单与组件操作；「恢复本版默认」会清空自建布局并恢复本版的默认展示，可通过撤销恢复。

此版本为本地预览，不创建 GitHub Release。
