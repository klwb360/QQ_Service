# Bilibili 视频助手示例

这个插件提供四个可供 QQ_Service AI 选择的工具：

| 工具 | 功能 | 外部作用 |
| --- | --- | --- |
| `popular_videos` | 获取热门候选视频 | 只读 |
| `search_videos` | 按主题搜索视频 | 只读 |
| `video_details` | 核对视频身份和简介 | 只读 |
| `comment_and_mention` | 发表评论并尝试 @ 预先配置的接收人 | 写入，需独立授权 |

把整个 `bilibili-assistant` 文件夹导入「模块 → 自定义插件」，为目标账号启用并应用。主应用中的触发方式、群、调用人、工具和写入授权仍需分别配置。插件没有自动计时器；只有获授权的请求才会触发调用。

## 筛选与分享

可以向接入的 QQ 发出明确需求，例如“找几个讲天文但不太晦涩的视频，说明推荐理由并把链接发到群里”。视频搜索和热门列表返回标题、简介、UP 主、时长与链接，AI 可以结合你在主应用填写的 Skill 做筛选。

**目前没有播放视频、解析音频、获取字幕或视觉理解。** 推荐理由必须说明依据是元数据，不能说“看完了”“已经看懂视频内容”。分享是把视频链接通过现有 QQ 回复渠道返回；这不是 Bilibili 私信转发功能，也不是无人值守的后台自动刷视频。

主应用可使用类似下面的 Skill 文本，文本本身不会授予任何权限：

```text
我偏好轻松、有出处的科普和生活技巧，避免标题党。
先寻找候选，再根据标题和简介说明推荐理由。
没有观看视频内容时明确说明依据有限。
只有用户明确要求发表评论并 @ 主人时，才考虑写入工具。
无法确认评论是否成功时停止，不要自动重复发送。
```

## 评论与固定 @ 接收人

主人先填写 `targetUid` 和与之对应的 `targetName`。这些是 Bilibili 接收提醒账号的 UID 与昵称，不是 QQ 号，也不必与执行评论的 Bilibili 账号相同。工具参数不能临时指定其他 @ 目标，评论正文也不允许夹带其他 @。

发表评论还需要当前插件自己的 `sessdata` 与 `csrf` 授权字段，分别对应同一次本人登录的 `SESSDATA` 和 `bili_jct` Cookie 值。主应用将这些字段放入本地加密凭据库，应用后才交给本插件；不应把它们写进普通参数、Skill、群消息、截图或仓库。当前没有集成 Bilibili OAuth 或扫码登录，只提供单个会话字段的高级配置，不读取系统浏览器的 Cookie。

工具会先核对 BV 对应的 aid，再向 Bilibili 评论接口提交一条正文、固定目标映射及 CSRF。它只执行一次 POST；请求超时、连接中断、返回内容损坏或缺少评论编号时，结果可能未知，必须先到网站核对，不能直接重复提交。平台可以拒绝登录、风控、频率、重复评论或评论区权限；插件停止并报告，不绕过验证或自动重试。

收到 `comment_submitted` 和 `rpid` 只代表平台返回了评论编号。`mentionNotificationVerified` 固定为 `false`：评论中的 @ 映射和实际提醒送达仍需要本人在网站验收。当前没有使用真实账号发表评论或验证 @ 通知。

## 接口与边界

- 只请求固定的 `https://api.bilibili.com` 主机，固定四个接口路径；不接受模型指定任意网址、脚本、命令或外部文件。
- 单次 HTTP 请求限时 10 秒，拒绝重定向，响应最大 1 MiB。插件整体限时 30 秒。列表最多 10 条、最多查询前 5 页，主人可设置更低条数上限。
- 登录凭据只放进发给 Bilibili 固定主机的 Cookie/CSRF，不出现在工具结果或错误中。服务端原始错误文本和响应头不会转发给 AI 或 QQ。
- 这些网页接口可能随平台升级、登录状态和地区限制变化，没有官方稳定性承诺。参考了社区的 [热门文档](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/video_ranking/popular.md)、[视频详情](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/video/info.md)、[评论接口](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/comment/action.md)。实际账号兼容性需要实机验收。
- 作为可信本地 Node.js 插件，它不是恶意代码沙箱；只导入你信任的源码。宿主的工具授权限制的是宿主调度，不替代第三方平台权限。

测试使用固定的假 HTTP 响应，覆盖参数、主机、编码、凭据、响应大小、错误停止与不重试；不连接真实 Bilibili 账号或发表评论。
